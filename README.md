# Cinder Stocking Pull · 丝袜穿脱插件

[下载 Windows 玩家安装包](https://github.com/anananlisr/CinderStockingPull-Releases/releases/latest/download/CinderStockingPull-Player.zip)

退出 Garry’s Mod，完整解压 ZIP，双击 `Install.cmd`。安装器会定位 Steam 游戏目录，备份被覆盖的插件文件。以后再次双击同一入口即可检查更新。安装器优先读取 GitHub 官方发布清单，并校验下载包的 SHA-256。已安装的最新版文件完整时会跳过安装。

手动安装可将包内的 `garrysmod` 文件夹合并到游戏根目录。模型和动画 DATA 单独安装。预设目录为 `garrysmod/data/cinder_stocking_pull/profiles/<预设ID>/`，放入该预设的 profile.json、motion.txt，以及袜子模式配套的 render.txt。
