# Cinder Stocking Pull · 丝袜穿脱插件

[下载 Windows 玩家安装包](https://github.com/anananlisr/CinderStockingPull-Releases/releases/latest/download/CinderStockingPull-Manual.zip)

退出 Garry’s Mod，完整解压 ZIP，双击 `Install.cmd`。安装器会定位 Steam 游戏目录，备份被覆盖的插件文件。双击 CheckUpdate.cmd 查询 GitHub 最新版。游戏内打开「选项 → Missile人物模型特性 → 全局丝袜设置」，点击「检查插件更新」。发现新版后，可自行打开 GitHub 发布页下载。

手动安装可将包内的 `garrysmod` 文件夹合并到游戏根目录。模型和动画 DATA 单独安装。预设目录为 `garrysmod/data/cinder_stocking_pull/profiles/<预设ID>/`，放入该预设的 profile.json、motion.txt，以及袜子模式配套的 render.txt。
